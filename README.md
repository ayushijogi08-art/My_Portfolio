# Ayushi Jogi - Full-Stack Developer Portfolio

**Live Demo:** (https://my-portfolio-z66z.onrender.com/)

## Overview
A high-performance, responsive developer portfolio built to showcase my full-stack engineering projects, technical skills, and interactive coding environment. The platform features an interactive code-editor UI theme designed to reflect a professional development environment.

## Tech Stack
* **Frontend:** React.js, Tailwind CSS (or standard CSS/HTML)
* **Backend:** Node.js, Express.js
* **Database & ORM:** Drizzle ORM
* **Hosting/Environment:** Replit

## Core Features
* **Interactive UI:** Custom-built code-editor aesthetic mimicking a real IDE environment.
* **Dynamic Project Showcase:** Scalable architecture to easily add and update featured projects like Nexa and Duplicate Sweeper.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.

## Local Setup & Installation
To run this project locally, clone the repository and execute the following commands in your terminal:

```bash
# Clone the repository
git clone [https://github.com/ayushijogi08-art/My_Portfolio.git](https://github.com/ayushijogi08-art/My_Portfolio.git)

# Navigate into the directory
cd My_Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
